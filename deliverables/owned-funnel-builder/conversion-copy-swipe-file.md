# Conversion Copy Swipe File

Use this with your coding agent when a funnel is structurally sound but the words are vague. Replace every bracketed field with a true fact. Never invent results, urgency, testimonials, or guarantees.

## One-sentence offer brief

> We help [specific buyer] get [specific outcome] without [costly old way] by giving them [concrete mechanism].

## Headline starters

- Get [outcome] without [painful method].
- [Do the desirable thing] before [time or event that matters].
- The [product category] for [buyer] who need [specific standard].
- Stop [repeated waste]. Start [desired result].
- Turn [input the buyer already has] into [valuable output].

## Hero support copy

> [Product] gives you [deliverable 1], [deliverable 2], and [deliverable 3], so you can [result] without [common delay].

## Button formulas

- Get [product] for [$price]
- Start [outcome] now
- Give me the [deliverable]
- Yes — help me [result]

The button should say what happens next. Avoid “Submit,” “Learn more,” and “Click here.”

## What is included

For each item, write one line using this shape:

> **[Named asset]** — [what it does] so you can [buyer result].

## Objection answers

- **“I am not technical.”** State the smallest action the buyer must take and what the agent handles.
- **“Will this work for me?”** Name the qualifying condition, then name who should not buy.
- **“I do not have time.”** Compare time-to-first-use with the old setup path using only honest estimates.
- **“I already use another tool.”** Explain ownership, switching cost, and what can remain unchanged.
- **“What happens after I pay?”** State the exact email, access link, first step, and support address.

## Order-bump formula

> Add [small companion asset] for [$price]. It removes [one immediate friction] from using [main product].

The bump should be useful immediately, cheaper than the main offer, optional, and unselected.

## Upsell formula

> You already have [main result]. Add [upgrade] if you also want [adjacent outcome] without [new obstacle].

One upgrade solves one adjacent job. Make “no thanks” clear and easy.

## Final pass for your agent

Ask:

> Audit this page for vague claims, repeated ideas, hidden next steps, invented proof, weak buttons, and sections that do not help the buyer decide. Preserve true facts and the offer’s voice. Return the five highest-impact edits first.
