# Offer content

Editable landing pages now live in `src/content/offers/`. Matching checkout funnels live in `src/content/funnels/`.

Use Keystatic for routine hand editing, the `funnel_create` MCP tool for a safe agent-created draft, or `npm run offer:new -- <slug> "Product name" "Headline words"` as a terminal fallback.

New drafts remain unpublished and contain obvious proof and delivery placeholders. Replace those honestly before publishing.
